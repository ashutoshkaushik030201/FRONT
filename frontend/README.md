# Nexus Frontend

React + TypeScript + Vite client for the Nexus Asset & Compliance Management System.

See the [root README](../README.md) for full setup instructions, architecture diagrams, and
default credentials.

## Scripts

- `npm run dev` — start the Vite dev server (proxies `/api` to `http://localhost:8000`)
- `npm run build` — type-check and build for production
- `npm run test` — run the Vitest + React Testing Library suite
- `npm run lint` — run Oxlint
